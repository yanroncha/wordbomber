# WordBomber — 英単語爆撃シューティング

ゼビウス風の縦スクロールシューティング。敵機との空中戦はなく、**地上砲台への爆撃のみ**。
砲台には英字が刻まれており、画面上部に表示された**お題単語の綴り順**に爆撃すると得点になります。

繰り返しの単調なBGM(ピロピロ)と、砲台の破壊音・被弾音・単語成立時のファンファーレが鳴ります。音は最初のキー入力または**最初のタッチ**で有効になります(ブラウザの自動再生制限のため)。`M` キーまたはスピーカーアイコンでいつでもミュートを切り替えられます(ミュート中は画面左下に表示)。iPhone の消音スイッチがONの場合は端末側で音が抑制されることがあります。

## 遊び方

| 操作 | キー(PC) | タッチ(スマホ) |
|------|------|------|
| 移動(上下左右) | ← → ↑ ↓ または W A S D | 画面をドラッグ(指の移動量ぶん相対移動) |
| 爆撃 | SPACE または Z | 右下の💣ボタン(長押しで連射) / 移動中に2本目の指でタップ |
| ポーズ | P または ESC | 右上の ⏸ アイコン |
| サウンドのミュート切替 | M | ⏸ の下のスピーカーアイコン |
| ゲーム開始 / リトライ | SPACE または ENTER | 画面をタップ |

タッチUIは**最初のタッチで自動表示**され、キーボードを押すと自動で消えます(PC/スマホの動的切替。タッチ対応端末では最初から表示)。ポーズ画面では「タップで再開」「リスタート」ボタンが表示されます。

- 自機の少し前方にある**赤い照準**の位置に爆弾が着弾します(投下から約0.4秒後)。
- お題単語の**次の文字**(黄色い枠)の砲台を爆撃すると1文字確定。単語完成でボーナス。
- 単語が成立すると、その**日本語訳が一時表示**され、短いファンファーレと爆発演出とともにボーナスが入ります。
- 単語が成立すると、フィールド上を飛んでいる**砲弾がすべて消えます**(仕切り直し)。
- 単語が成立するたびに、地形(森・平地・砂漠・海)が次のバイオームへ切り替わります。
- **順番を間違えるとミス**。単語の進捗がリセットされ、機体を1機失います。
- 地上砲台は**ゆっくり反撃**してきます(フィールド上の砲弾は最大5発)。被弾すると爆発して**機体を1機失います**(初期8機、0でゲームオーバー)。被弾直後は短時間無敵(点滅)。
- **1000点ごとに残機が1機増えます**(「1UP!」表示。7機以上は右上を「▲×N」で表示)。
- レベルが上がる瞬間は**ワープ演出**(約2秒の高速スクロール+スピードライン+機体点滅+上昇音)で次のエリアへ移動します。ワープ中は無敵で、砲台も撃ってきません。
- 文字のない無地バンカーは爆撃しても小得点のみでペナルティなし。

## ポーズ(カンニング防止)

`P` / `ESC` でポーズ。ポーズ中は**フィールドとお題単語を完全に隠す**ので、盤面を見て単語を推理し続けることはできません。

- `P` / `ESC` … 再開
- `R` … 最初からリスタート

## 虫食いモード(難度上昇)

単語を3個完成するごとにレベルが上がります。レベルが上がると:

- 単語が長くなる(3文字 → 最大7文字)
- お題が**虫食い**になる(`S ? I P` のように一部が `?` で隠される)
- スクロールが速くなり、デコイ砲台が増え、砲台の反撃も少し激しくなる

虫食い部分は**辞書に存在する英単語として成立する文字なら正解**扱いです
(例: お題 `C?T` なら CAT でも CUT でも OK。完成した単語で得点)。
虫食い位置の正解は通常の2倍の得点。ミスなしで単語を連続完成するとコンボ倍率が上がります。

## 起動方法

`index.html` をブラウザで開くだけで動きます(ビルド・サーバ不要)。

ローカルサーバを使う場合:

```
python -m http.server 8000
# → http://localhost:8000/
```

## 単一ファイル版のビルド(Artifacts 公開用)

```
node build.js
```

`dist/wordbomber.html` に CSS/JS をすべてインライン化した自己完結の1ファイルが生成されます。
このファイルの内容を claude.ai に貼り付ければ、そのまま **Artifact** として公開・共有できます
(外部リソース参照なし。localStorage が使えない環境ではハイスコア保存だけが無効になります)。

## ファイル構成

```
index.html        エントリポイント(script を依存順に読み込み)
css/style.css     ページスタイル
js/words-data.js  辞書(3〜7文字の英単語 + 日本語訳)
js/input.js       キー入力
js/background.js  バイオーム地形(森・平地・砂漠・海をランダム連結)
js/word.js        お題単語・虫食い・候補集合判定
js/spawner.js     砲台スポーン(必要文字の保証供給)
js/turret.js      砲台エンティティ(反撃タイマー付き)
js/player.js      自機・照準・被弾/無敵
js/bomb.js        爆弾と爆発パーティクル
js/enemyfire.js   砲台の反撃弾と自機被弾判定
js/audio.js       WebAudio 合成のBGM・効果音
js/touch.js       タッチUI(ドラッグ操縦・💣ボタン・⏸/🔊アイコン、PC/スマホ動的切替)
js/hud.js         スコア・お題表示・機体数・単語成立バナー
js/game.js        状態機械(タイトル/プレイ/ポーズ/ゲームオーバー)とスコアリング
js/main.js        ゲームループ
build.js          単一HTML生成スクリプト
```
